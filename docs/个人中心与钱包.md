# 个人中心、主页、历史记录与模拟钱包

## 如何使用

在 IDEA 中停止并重新运行原来的 `Application`（继续使用当前 MySQL/Redis 配置，不需要切换dev）。前端保持 `npm run dev` 运行即可。

数据库升级由 Flyway 自动完成：V2 将旧核心表检查并转换为 InnoDB，V3 添加个人资料字段、头像表、钱包及账本表，并为已有用户创建零余额钱包。不会删除已有账号或修改密码。新注册用户自动创建钱包。

登录后点击顶部头像或“个人中心”进入编辑页。学生手机端增加“我的”“钱包”“接取记录”入口，认证入口保留。

## 功能入口

- **个人中心**：更换头像，设置昵称、生日和简介。学生可选年级并填写专业。
- **预览我的主页**：显示公开资料；其他用户可从岗位的企业名称、接取人头像或名称进入对应主页。
- **发布记录**：企业查看所有历史岗位，进入每个岗位查看接取人、接取时间和结算状态。
- **接取历史**：学生查看所有接取岗位、企业主页入口、接取时间、兼职费结算金额与时间。
- **企业钱包**：模拟充值，并查看发放流水。
- **学生钱包**：查看可用/冻结余额、收入与支出流水、发起或撤销模拟提现。

## 钱包体验顺序

1. 企业发布岗位，学生接取（仍遵循原有实名认证权限）。
2. 企业进入“企业钱包”，点击“模拟充值”。
3. 企业进入“发布记录” → 对应岗位 → 接取人 → “发放兼职费”。
4. 输入结算总额并确认模拟发放；日薪仅作为建议值，可根据工作天数填写总额。
5. 学生进入钱包，刷新即可看到余额与兼职费收入；接取历史显示已结算金额。
6. 学生点击“申请提现”，金额先冻结，申请为“待处理”；点击“撤销申请”会退回可用余额。

当前采用模拟资金，充值不会扣真实银行卡资金，提现不会实际到账。每条接取记录只能结算一次，不支持追加支付、退款或付款金额修改。新增真实资金业务前需要支付提供方接入、对账、异常补偿和提款审核流程；不能将模拟余额直接转换为真实余额。

未认证测试账号可以编辑个人资料和查看自己的空钱包。原有认证规则保持不变，创建测试账号不会自动开放发岗或接取权限。

## 主页隐私

公开给其他登录用户的内容：头像、昵称、简介、角色、认证状态、加入日期；学生还有年级、专业和已认证学校；企业显示已认证单位。

不公开：生日、手机号、邮箱、密码、实名认证姓名/证件/学号、钱包、个人接取历史。岗位接取名单仅该岗位发布者可见。
