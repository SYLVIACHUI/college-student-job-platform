# 企业与学生分表

企业账号保存在 MySQL 的 `publisher_user`，学生账号保存在 `student_user`。这两张表各自保存手机号密文、密码哈希、个人资料和实名认证状态。

| 用途 | 文件（相对于项目根目录） |
| --- | --- |
| 企业实体 | `backend/src/main/java/cn/campus/jobs/entity/PublisherUser.java` |
| 学生实体 | `backend/src/main/java/cn/campus/jobs/entity/StudentUser.java` |
| 企业数据库操作 | `backend/src/main/java/cn/campus/jobs/mapper/PublisherUserMapper.java` |
| 学生数据库操作 | `backend/src/main/java/cn/campus/jobs/mapper/StudentUserMapper.java` |
| 企业页面：登录、认证、工作台、发布岗位 | `frontend/src/pages/publisher/PublisherApp.vue` |
| 学生页面：登录、认证、发现兼职、领取岗位 | `frontend/src/pages/student/StudentApp.vue` |
| 两端共用的请求与会话逻辑 | `frontend/src/composables/usePortal.js` |
