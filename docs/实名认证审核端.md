# 实名认证审核端

访问前端的 `/admin`（本地通常为 `http://localhost:5173/admin`）。使用独立审核账号登录，企业和学生账号不能进入。

1. 企业或学生在自己的实名认证页面提交资料，状态变为待审核。
2. 审核员在待审核申请中按身份筛选，点击“查看并审核”。
3. 核对企业的单位、姓氏、名字和身份证号，或学生的学校、姓名和学号。
4. 填写审核意见并选择通过或驳回，确认提交。通过后开放发布或接取权限；驳回后允许用户修改资料并重新提交。
5. 审核记录显示处理人、时间、结果和意见。意见应描述审核结论或修改要求，不要复制敏感资料原文。

此页面是人工处理工具，不会自动核验证件真伪，也没有接入外部 AI。

数据库通过 V6 自动增加 `review_admin`（独立审核账号，BCrypt 密码）和 `review_action`（人工审核操作记录）。原认证历史继续保留。审核按申请版本校验，已处理或已重新提交的旧申请无法重复审批。

审核端使用独立 HttpOnly Cookie，4 小时会话存储在 Redis（dev 环境为内存），普通账号会话不能用于审核接口。页面关闭资料弹窗或退出时清空敏感数据，接口禁止缓存。

账号只允许通过显式的一次性命令初始化，没有公开注册接口，也没有自动启用的默认密码。在进程环境中提供 `REVIEW_ADMIN_USERNAME`、`REVIEW_ADMIN_PASSWORD`，以 `--spring.main.web-application-type=none --app.bootstrap-review-admin=true` 启动后端即可创建；必须继续使用原数据库配置和加密密钥。同名账号不会覆盖密码。

主要文件：`frontend/src/pages/admin/ReviewApp.vue`；后端 `ReviewAdminController.java`、`ReviewAdminService.java`、`ReviewAdminBootstrap.java`。
