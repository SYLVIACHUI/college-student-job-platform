# 兼职岗位与接取名额

## 数据关系

`job` 保存兼职工作，Java 实体为 `cn.campus.jobs.Job`。`publisher_id` 外键关联 `publisher_user.id`，发布单位实时读取企业认证信息，客户端不能指定其他企业作为发布者。

| 字段 | 含义 |
| --- | --- |
| title / category | 标题 / 兼职类别 |
| required_count | 需要人数，新发布范围 1–200 |
| description / requirements | 具体工作内容 / 工作要求 |
| location | 工作地点 |
| pay / pay_unit | 报酬金额（DECIMAL，精确到分）/ 计价单位，新岗位按每人每次总额 TOTAL |
| starts_at / duration_minutes | 本地开始时间 / 持续分钟数 |

`job_application` 是接取关系表，`student_id` 外键关联 `student_user.id`，同一学生只能加入同一岗位一次。昵称、头像、姓名密文、学号密文、学校从学生实体读取，不在岗位表重复存储。`acceptance_status` 在查询时计算：无人接取为 UNACCEPTED（未接受），有人接取为 ACCEPTED（已接受）；`remaining` 为需要人数减去接取人数。满员与已开始的岗位不能继续加入。

## 界面和权限

- 列表仅返回摘要字段，展示类别、标题、发布单位、剩余名额、兼职时间和持续时间；点击标题或“查看详情”打开详细内容。
- 详情的公开接取人仅包含用户 ID、昵称、头像，不包含真实姓名、学号或学校。
- 学生点击空圆圈中的加号，确认时间、地点与报酬后加入。已加入者显示圆形头像，点击可访问公开主页。点击企业单位进入企业主页。
- 本岗位发布者通过“查看接取人资料 / 发放兼职费”访问私有资料；接口先验证岗位归属，再解密真实姓名与学号，并返回学校。其他企业及学生均不能调用此接口获取资料。公开学生主页不再展示学校。
- 加入接口在事务中锁定岗位记录，校验权限、重复接取、开始时间、剩余名额后插入，避免并发超额。

## 接口

- `GET /api/jobs`：摘要列表（企业只看自己发布的岗位）。
- `GET /api/jobs/{id}`：岗位详情和公开接取人列表。
- `POST /api/jobs`：已认证企业发布。
- `POST /api/jobs/{id}/apply`：已认证学生确认加入。
- `GET /api/jobs/{id}/applicants`：仅岗位所有者可读取的接取人资料及结算状态。

发布请求示例（开始时间必须晚于当前时间）：

```json
{"title":"迎新活动助理","category":"活动执行","requiredCount":3,"description":"现场签到和引导","requirements":"准时到场，认真负责","location":"大学生活动中心","pay":180.50,"startsAt":"2099-05-06T09:00:00","durationMinutes":240}
```
